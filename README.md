# RSD Life OS

**You know exactly what to do — and still can't make it happen. The same conflict keeps replaying in your closest relationships. Money comes and goes and never stays. You've read the books, understood every concept, and nothing changes.**

This skill was built for those moments.

It is a complete life operating system, compiled from the book *RSD Life OS* (《RSD人生优化系统》) by **Gu Yang (RSD Kin)**: six named tools, three cosmic laws, three identities, four journeys, and the 2=1+1 Dao/Li lens — each with a stated purpose, an operating procedure, and a failure mode.

Not motivation. Not concepts. A **toolkit** — procedures you run when you're stuck.

## What it answers

| The question you're actually asking | What the skill runs |
|---|---|
| "Why does the same thing keep happening to me?" | RSD Analysis Tool — read the pattern's form, name the energy sustaining it (ch 2) |
| "I'm stuck / everything is falling apart" | RSD Rebuilding Tool — R→S→D: own it, see it, act with the flow (ch 7) |
| "I can't stop spiraling" | RSD Awakening Tool — reposition from object of thought to sovereign (ch 6) |
| "I'm drained, reactive, can't sleep" | RSD Charging Tool + Observation Tool (ch 8) |
| "Should I do this?" | Navigation Tool — +1/−1 calibration, tested against the three laws (ch 9) |
| "Why can't we just get along?" | ch 11 — emotion, conflict, communication |
| "Why is money so hard to keep?" | ch 12 — wealth as the receipt of altruistic value |
| "What's my direction in life?" | Four Journeys: self-cultivation → family → duty → world (ch 10) |

## Install

Agent Skills are directories with a `SKILL.md` at the root. Clone into your agent's skills directory:

```bash
git clone https://github.com/rsd-life-os/rsd-life-os.git
# then point your agent's skill loader at this folder
```

Compatible with any agent that reads the Agent Skills open standard (SKILL.md + lazily-loaded resource files).

## What's inside

```
SKILL.md          main index (~2.8k tokens) — load this first
glossary.md       every named term, one line each
patterns.md       recurring structures and failure modes the book names
cheatsheet.md     one page: diagnosis table, tool cards, hard limits
chapters/         the full book, one file per chapter, loaded on demand
  front-matter.md        The Call of Our Times; Author's Declaration
  ch01..ch15.md          the fifteen chapters
  final-chapter.md       Becoming the Light Source
  about-gu-yang.md       About the author
  fortune-note.md        Fortune Optimization Note
```

The skill loads a chapter file only when the conversation needs that chapter. Nothing is preloaded.

## The framework in 30 seconds

- **2=1+1** — every thing = **Dao** (life energy, the drive) + **Li** (operating law, the form). Read the form first, name the energy second.
- **Six tools** — Analysis (Truth Insight Device) · Awakening (Sovereignty Reset Device) · Rebuilding (Destiny Optimizer) · Charging (Body-Mind Charger) · Observation (Body-Mind Manager) · Navigation (Behavior Calibrator).
- **Three cosmic laws** — Survival (Existence & Continuation) · Behavior (Wu Wei, Altruism, Equality) · Cause & Effect (Behavioral Assessment & Energy Settlement).
- **RSD code** — R (Reality | Accountability) → S (Spirit | Shattering Attachments) → D (Dao | Going with the Flow). Order is load-bearing.

## Scope and limits

This skill is a **companion to the book, not a replacement for it**. It indexes and applies the author's frameworks; it does not reproduce the book's text.

- **Not medical, psychological, or financial advice.** Where there is illness, see a clinician; where there is crisis, seek human help immediately.
- **It does not predict the future.** The book explicitly forbids it.
- **It does not recruit, sell, or promote.** No products, no downline, no membership funnel.
- **No guarantees of effects.** Results stem from how accurately, frequently, and consistently the system is practiced.
